# 分段电价定价方法论

## 适用场景

当项目参与机制电价竞价时，电价分为**两个阶段**：
- **机制期**（第1-N年）：固定机制电价按一定比例覆盖，剩余电量按市场化结算
- **市场化期**（第N+1~25年）：全部电量按市场化方式结算

## 定价计算步骤

### 第1步：计算各期的加权均价

```
机制期加权均价 = 机制比例 × 机制电价 + (1-机制比例) × 现货价
市场化期加权均价 = 中长期比例 × 中长期价 + 现货比例 × 现货价
```

其中 `中长期比例 + 现货比例 = 1.0`。

### 第2步：计算有效电价（扣除考核和费用）

```
机制期有效电价 = (加权均价 + 绿电溢价 - 两个细则考核) × (1 - 市场费用率)
市场化期有效电价 = (加权均价 + 绿电溢价 - 两个细则考核) × (1 - 市场费用率)
```

### 第3步：计算25年加权平均值（用于简单测算）

```
25年加权均价 = (N × 机制期有效电价 + (25-N) × 市场化期有效电价) / 25
```

> ⚠️ 分段结果更准确，应优先使用。加权平均值仅作为简化估算。

## 广东潮州案例

### 原始参数表

| | 现货交易比例 | 40% |
| | 现货价格 | 0.2000元/kWh |
| | 加权均价 | 0.2900元/kWh |
| | 两个细则考核 | -0.015元/kWh |
| | 市场费用分摊 | -2% |
| | **有效电价** | **0.2695元/kWh** |

### 计算验证

```
机制期有效电价 = (0.8×0.36 + 0.2×0.20 - 0.015) × 0.98 = 0.3067
市场化期有效电价 = (0.6×0.35 + 0.4×0.20 - 0.015) × 0.98 = 0.2695
25年加权均价 = (12×0.3067 + 13×0.2695)/25 = 0.2874
```

### VAT 修正

使用分段电价时，增值税基准价需要用**含税加权均价**（扣除考核和市场费之前的加权均价）：

```python
# 在 VAT 计算中，替换 vat_out 的计算
vat_base = 0.3280 if i < 12 else 0.2900  # 各期含税加权均价
vat_out = gen[i] * vat_base * vat_rate / (1 + vat_rate)
```

## 常见错误

1. ❌ 把现货价设置到 `mlt_price` 上
   - ✅ 现货和中长期是不同交易品种，分别对应 `spot_price` 和 `mlt_price`
2. ❌ 用25年单电价一刀切处理分段定价
   - ✅ 应使用 `price_schedule` 或条件判断分段计算
3. ❌ 折旧用经营期年限（25年）计算
   - ✅ 折旧年限一般是20年（残值5%直线法），和经营期25年不同
4. ❌ 增值税基准沿用有效电价
   - ✅ 分段定价时增值税基准用含税加权均价（有效电价÷0.98+0.015的反算）
